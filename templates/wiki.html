Neue Features

1Advanced Channel Cache System

4 verschiedene Cache-Modi für optimale Performance

lazy-ram (Standard)

Verhalten: Cache on-demand, nur im RAM
Vorteil: Minimaler Speicherverbrauch
Ideal für: Kleine Setups, wenige Portale

hybrid (Empfohlen)

Verhalten: Pre-Cache, RAM + Disk
Vorteil: Schnell + Persistent
Ideal für: Produktiv-Systeme

Einstellung: Settings → Channel Cache Mode
Dokumentation: CACHE_MANAGEMENT.md

2Intelligentes MAC-Fallback

Automatisches Durchprobieren aller MACs bis Channel gefunden

❌ Original-Verhalten
  1. Versuche MAC1 → Nicht gefunden
  2. Cache MAC1 (leer)
  3. Versuche MAC2 → Gefunden
  4. Nächster Zugriff: MAC1 (leer) → Fehler!
✅ Neues Verhalten
  1. Probiere MAC1 → Nicht gefunden → Weiter
  2. Probiere MAC2 → Gefunden!
  3. Cache MAC2 mit Channel
  4. Nächster Zugriff: MAC2 → Instant!
Vorteil: Weniger fehlgeschlagene Streams, intelligenteres Caching

3XC API Portal-Filterung mit Namen

Filterung nach Portal-ID ODER Portal-Name

Mit Portal-ID
/get.php?username=test&password=test
&portal_id=portal_1

✅ Eindeutig
✅ Schneller

Mit Portal-Name (NEU!)
/get.php?username=test&password=test
&portal_id=My%20Portal

✅ Lesbarer
✅ Einfacher zu merken

Dokumentation: XC_API_PORTAL_FILTERING.md
