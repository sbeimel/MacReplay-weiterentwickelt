1Advanced Channel Cache System

4 Cache-Modi für optimale Performance:

lazy-ram (Standard)
Cache on-demand, minimaler RAM. Ideal für: Kleine Setups, wenige Portale
ram
Pre-Cache beim Start, alles im RAM. Ideal für: Viel RAM verfügbar
disk
Pre-Cache auf Disk, persistent. Ideal für: Wenig RAM, häufige Neustarts
hybrid (Empfohlen)
RAM + Disk, beste Performance. Ideal für: Produktiv-Systeme
Einstellung: Settings → Channel Cache Mode
Performance: Bis zu 50x schnellere Channel-Zugriffe!
2Intelligentes MAC-Fallback

Automatisches Durchprobieren aller MACs bis Channel gefunden:

❌ Vorher:
MAC1 probiert → Nicht gefunden → MAC1 gecacht (leer) → Fehler!
✅ Jetzt:
MAC1 → MAC2 → MAC3 → Gefunden! → Nur richtige MAC gecacht
Vorteil: Weniger fehlgeschlagene Streams, intelligenteres Caching

Quick Start

1. Zugriff:

  • Navigation → Vavoo Tab
  • Oder direkt: /vavoo_page
  • Login: Gleiche Credentials wie MacReplayXC

2. Playlists:

  • Einzeln: http://host:4323/playlist/DE.m3u
  • Kombiniert: http://host:4323/playlist/DE_FR_IT.m3u

3. Konfiguration:

  • HOST ENV: Deine öffentliche URL
  • Port 4323 freigeben (docker-compose.yml)
  • Automatischer Start via start.sh

4. Vorteile:

  • Single Container (alles in einem)
  • Tabler Dark Theme (passt perfekt)
  • Shared Environment (HOST-Variable)
Dokumentation: Detaillierte Setup-Anleitung in docs/vavoo/QUICKSTART.md

Schnell-Tipps

🚀 Für beste Performance:
  • Cache Mode: hybrid
  • Cache Duration: unlimited
  • MAC Retry: immer aktiv
  • Test Streams: false (wenn Portale stabil)
  • ffprobe Params: Balance (schnell & zuverlässig)
💾 Für minimalen RAM:
  • Cache Mode: disk
  • Cache Duration: 1h
  • Stream Method: redirect
  • Test Streams: false
  • ffprobe Params: Ultra Fast (maximale Geschwindigkeit)
🔒 Für Sicherheit:
  • Enable Security: true
  • Passwort ändern!
  • Public Playlist Access: false
📺 Für Plex/Emby:
  • Enable HDHR: true
  • Stream Method: redirect
  • Public Playlist Access: true
🚀 Vavoo Optimal:
  • RES Scan: false (nur bei Problemen)
  • Stream Mode: Proxy (für Internet)
  • Filter: false (alle Channels)
  • Rebuild on Start: true
